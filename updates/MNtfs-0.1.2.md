# MNtfs 0.1.2

- Added signed Sparkle updates from the menu bar, with daily update checks.
- Updates wait until MNtfs disk operations finish and drives using its extension are ejected.
- Reduced repeated NTFS metadata reads and unnecessary read-modify-write I/O during file copies.
- Fixed FSKit root directory identity and visibility for Finder drive icons.
- Strengthened drive identity checks before formatting and fixed NTFS timestamp persistence.
